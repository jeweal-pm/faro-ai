# ADR-0006: LocalLLM Support

- **Status:** Accepted
- **Date:** 2026-10-04
- **Deciders:** Jakapong Chan-o ( PM )

## Context

เนื่องด้วยลูกค้าบางเจ้าไม่สะดวก ส่งข้อมูลออกไปประมวลประมวลผลภายนอก เนื่องด้วยเหตุผลด้านความลับของข้อมูล จะต้องทำการประมวลผลผ่าน server ที่ทางลูกค้าจัดเตรีมไว้เท่านั้น

## Decision
ทำให้ Faroai รองรับการทำ LocalLLm โดยสามารถเชื่อต่อกับ api ของ lmstudio ได้


กติกาที่ทีมต้องทำตาม:

- การพัฒนา rag ของ faro ai สำหรับงาน local ต้องมีการพัฒนาที่ ครอบคลุมมากพอที่จะทำงานผ่าน model ที่ฉลาดน้อยกว่า เพราะ model ที่ ใช้ใน lmstudio 
จะฉลาดไม่เท่า  model ที่เราใช้ผ่าน openrouter 

- ทุกๆครั้งที่มีการใช้ model
