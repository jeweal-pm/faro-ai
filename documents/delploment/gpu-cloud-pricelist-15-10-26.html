ข้อควรรู้ก่อนเปิดเครื่อง

  • เริ่มประหยัด: AWS g4dn.xlarge (T4 16 GB) ที่ประมาณ $0.526/ชม. รวม instance หรือ DigitalOcean RTX 4000 Ada 20 GB ที่ $0.76/ชม. โดยราคาจริงขึ้นกับ region และภาษี
  • ราคาของ Google Cloud P4/T4 ในตารางเป็นเฉพาะค่า GPU ต้องบวก VM host และ disk ก่อนเทียบกับราคารวมของ AWS/DO/Runpod
  • Runpod แสดงตัวเลือก Cloud หลายแบบ ให้ดูยอดรวมและ storage ที่เลือกก่อนสร้าง Pod; ค่า volume ที่เก็บไว้หลังหยุดงานอาจยังมีค่าใช้จ่าย
  • AWS/GCP หยุดคิดค่า compute/GPU เมื่อ instance อยู่สถานะ stopped แต่ยังคิดค่า disk/storage ที่เก็บไว้. DigitalOcean GPU Droplet ยังคิดเงินแม้ power off จึงต้อง Destroy เพื่อหยุดค่า compute; เก็บข้อมูลที่ต้องใช้ต่อใน volume/storage ที่คิดค่าบริการตามจริง
  • ตั้ง budget alert ก่อนเริ่ม, บันทึก dataset/model กลับลงเครื่องของคุณ และตรวจว่า instance ถูก Stop หรือ Destroy ตามรูปแบบ billing ของผู้ให้บริการ
  • ราคานี้ไม่ใช่ใบเสนอราคา และไม่รวมภาษี/ค่า storage/network เว้นแต่ระบุไว้ ราคาและ GPU ที่ว่างเปลี่ยนได้
