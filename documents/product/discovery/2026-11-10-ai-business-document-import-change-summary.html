สรุปไฟล์ที่แก้ไข
ระบบนำเข้าเอกสารธุรกิจ

สรุปเฉพาะไฟล์ที่เกี่ยวกับงาน Document Import รอบนี้ แยกตามส่วนที่รับผิดชอบ เพื่อให้เปิดดูได้ว่าไฟล์ไหนทำหน้าที่อะไร และส่วนไหนยังรอตั้งค่าก่อนใช้งานจริง ไฟล์อื่นที่เปลี่ยนอยู่ใน workspace จากงานก่อนหน้าไม่ได้รวมไว้ในรายการนี้

อัปเดต 10 พฤศจิกายน 2026รอบแรก: OCR และตรวจทานเปิดบนเครื่อง dev แล้ว

ภาพรวมสถานะ

เวอร์ชันนี้วางฐานรับไฟล์ แยก tenant ประมวล OCR และเปิดให้ผู้ใช้ตรวจผลก่อน ยังไม่สร้างข้อมูลธุรกรรมใน GIS

ทำในโค้ดแล้วอัปโหลด PDF/PNG/JPEG, อ่าน text layer หรือ OCR ภาษาไทย/อังกฤษ, แสดงหน้าเอกสารและข้อความ, ใส่ป้ายประเภทด้วยคน และลบข้อมูล
เปิดบนเครื่อง dev แล้วmigration 021, worker credential, encryption key และ feature flag ถูกตั้งค่าแล้ว; API/Backoffice/worker กำลังทำงานใน Compose profile `document-import`
ยังเป็นงานระยะถัดไปAI จำแนก/ดึงฟิลด์อัตโนมัติ, ตรวจเทียบ master, GIS preview/write, Qdrant หรือการเรียนรู้จาก correction

รายการไฟล์แยกตามส่วน

รายการด้านล่างระบุไฟล์ที่เพิ่มหรือแก้เพื่อรองรับ feature นี้ โดยไฟล์ที่มีงานเดิมอยู่แล้วถูกแก้เฉพาะจุดเชื่อมต่อที่เกี่ยวข้อง

ขอบเขตความปลอดภัยและข้อมูล

ไฟล์ถูกผูกกับ tenant/ผู้ใช้, ตรวจชนิดและลายเซ็นไฟล์, จำกัดขนาดและผล OCR, เข้ารหัสต้นฉบับและ preview, ให้ worker ทำงานใน network ที่ไม่ออกอินเทอร์เน็ต และไม่ส่งไฟล์ไปยัง AI provider ในรุ่นนี้ การลบจะซ่อนงานและล้างข้อความ/ต้นฉบับทันที ส่วน preview ที่เข้ารหัสจะถูก worker ลบต่อแบบ asynchronous

กำหนด retention: ไฟล์ต้นฉบับ 24 ชั่วโมง และผล OCR/ข้อมูลตรวจทาน 7 วัน ประเภทเอกสารใน registry เป็นสถานะรองรับ OCR เท่านั้น ยังไม่มีการยืนยันว่าระบบเข้าใจเอกสารนั้นหรือสามารถนำเข้าธุรกรรมได้

สิ่งที่ยังไม่ดำเนินการ

  • ผ่าน build และ synthetic OCR/integration checks บน local แล้ว แต่ยังไม่ได้ทดสอบด้วย browser session ของผู้ใช้
  • Feature flag ยังคงปิดเป็นค่าเริ่มต้นใน Compose; เครื่อง dev นี้เปิดใน .env ที่แยกจาก config ใน repository
  • ยังไม่มี AI จำแนกชนิด/ดึงข้อมูล, mapping กับ GIS, preview ธุรกรรม หรือเขียนข้อมูลเข้า GIS
  • ยังไม่มีการส่งเอกสารหรือ correction เข้า Qdrant, RAG หรือการฝึกโมเดล

แก้ไขตามวันที่ในระบบ: 10 พฤศจิกายน 2026 (Asia/Bangkok). ตรวจ runtime ใน local dev เท่านั้น; parser adversarial review, capacity benchmark และ production deployment ยังไม่ผ่านการตรวจ
