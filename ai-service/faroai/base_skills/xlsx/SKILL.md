Create a private Excel workbook from the verified, structured PO lines currently displayed to the user. Preserve numbers as numbers and neutralize formula-like text so cells cannot execute formulas. A prompt may revise print orientation, paper size, typography, title/body text color, table-header text/background colors, footer, column visibility/order and the placement of an attached PNG/JPEG image through a validated layout patch. Include only loaded lines in the current view and state when a PO is partially loaded. Each revision creates a new version with an exact private download that expires after 24 hours. Do not send, publish or store the workbook in Qdrant.
